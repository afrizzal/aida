    - Punctuation and letters after a name (R2-1): delete the trailing space and type "," (or ".", or "s") directly after an inserted name; the span stays intact and its id is still returned by reconcileMentionIds; stripMentionTokens removes the name and leaves the "," (or ".", or "s").
    - Partial deletion (R2-1): backspace on the last letter of an inserted name, or typing a character inside it, removes the whole inserted name from the text (a typed character stays), drops its id, and leaves no fragment of the name; a selection that covers part of a name and is replaced by a paste does the same.
    - Shared prefix (R2-1): members named "Zeta" and "Zeta Prime" are both inserted; a partial deletion inside "Zeta Prime" drops only that id and keeps "Zeta" intact; stripMentionTokens removes both names; with only "Zeta" inserted, a plain "@Zetaline" typed by the agent stays.
    - Edits before a span shift it; edits after it leave it unchanged.
    - Safety net: a pasted copy of an inserted "@{name}" followed by "," (plain text, no span) is removed by stripMentionTokens; a plain "@someone" stays.
    - mentionDraftReducer: setMode internal→public returns the stripped text, empty spans and the switch note on; public→internal clears the note; loadDraft sets the draft text, mode public, empty spans and empty insertedNames; sent clears text, spans, insertedNames and the note.

  </behavior>
