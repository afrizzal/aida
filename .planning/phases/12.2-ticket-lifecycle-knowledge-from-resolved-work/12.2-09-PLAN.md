## Trust Boundaries

| Boundary | Description |

| server page to browser | Proposal text is AI output from customer data; rendered only as text or through renderMarkdown |
| browser to server actions | Version and edited text are untrusted; the server re-validates |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-12.2-40 | Tampering | Stored XSS through AI-generated Markdown in the preview | high | mitigate | Preview HTML only from renderMarkdown on the server (the existing KB renderer); the raw body is shown only in a textarea |
| T-12.2-41 | Elevation of privilege | Publish without review by direct URL or a hidden button | high | mitigate | Page and actions check membership and role server-side; publish requires the dialog's explicit action and the server's conditional update |
| T-12.2-42 | Repudiation | Publishing an unsaved version | medium | mitigate | Publish disabled while dirty; server publishes the stored row at the expected version |
| T-12.2-43 | Information disclosure | Customer details published unnoticed | medium | transfer | The reviewer is told on the page, the body help and the publish checklist (owner item 12.2-o1); a human reads every generated article before real use |
</threat_model>
