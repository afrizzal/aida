- **Fix:** ran the same command under a pseudo-terminal (`script -q /dev/null …`) and answered its "create this migration?" confirmation with yes. The command still only created the file (`--create-only`), against the scratch database only.
- **Commit:** 4a9c298

**2. [Rule 3 - Blocking] One-to-one composite relation refused by Prisma validation**
- **Found during:** Task 1
- **Issue:** `publishedArticle KbArticle? @relation(fields: [organizationId, publishedArticleId], …)` with a one-to-one back-relation needs `@@unique([organizationId, publishedArticleId])`.
- **Fix:** the back-relation on KbArticle is the list `kbProposals KbProposal[]`; `publishedArticleId String? @unique` (as the plan specifies) keeps it at most one in the database. No extra index added.
- **Commit:** 4a9c298
