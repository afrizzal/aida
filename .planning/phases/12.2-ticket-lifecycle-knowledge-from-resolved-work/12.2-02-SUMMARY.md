## Run decision K51 as implemented

- **isTicketPageUrl:** WHATWG `new URL(candidate, "https://aida.invalid/kb/article")` (a `www.` candidate gets `https://`), `decodeURIComponent` of the pathname once, case-insensitive `startsWith("/tickets/")`. A candidate the parser rejects is ignored. `/tickets` (the list, no trailing segment) is allowed.
- **containsTicketLink (raw text, title and body):** Markdown inline link and image destinations, reference definitions (destination on the same or the next line), autolinks, `href` and `src` attribute values in the text, bare `scheme://` and `www.` URLs wherever they appear, and every whitespace-delimited token after stripping a leading run of TOKEN_WRAP_LEADING `( [ { < " '` backtick and a trailing run of TOKEN_WRAP_TRAILING `) ] } > . , ; : ! ? " '` backtick, when it begins with `/`, `./` or `../` (review R3-3).
- **renderedBodyLinksToTicket (body only):** `renderMarkdown(body)` parsed with rehype-parse (fragment) inside unified, every element visited with unist-util-visit, every value of RENDERED_URL_PROPERTIES = href, src, cite, longDesc, srcSet (each srcSet entry's first whitespace part) tested with isTicketPageUrl (review P8). These are exactly the URL attributes hast-util-sanitize 5.0.2's defaultSchema keeps (render.ts adds only target and rel on `a`); Markdown produces URLs only on `a` and `img`. No regular expression over HTML.
- Escaped destinations: ``[guide](\/tickets\/abc)``, `[guide](&#47;tickets/abc)` and ``![x](\/tickets\/abc)`` are missed by the raw candidates (the tests assert this for the two links) and caught by the rendered href or src.

### Documented false positives and limits

- **False positive (fail-closed):** a link to another site whose path starts with `/tickets/` is refused (for example `https://status.example.com/tickets/123`, `//status.example.com/tickets/1`, `www.status.example.com/tickets/1`).
- **Malformed percent escape (fail-closed):** a candidate whose path holds a malformed escape counts as a ticket link. Probe: the body `see https://example.com/100%` is refused with TICKET_LINK.
- **Ticket number in free prose is allowed:** `Same cause as ticket #123; the tickets queue was slow.` and the title `Ticket #123 follow-up` pass. Free prose is the reviewer's responsibility under the publish checklist.
- **Known limit (R3-3):** a path joined to a word by a character outside the wrapping sets and outside whitespace is not found. Probes, both accepted: `see:/tickets/abc`, and `**/tickets/abc**` (Markdown emphasis, since `*` is not in the sets; it renders as plain text with no element). Detecting every free-form reference to a ticket is not claimed.

## KB form length note

The existing KB form (`src/components/kb/kb-article-form.tsx`, zod `min(3)` and `max(120)` on a string) counts title length in UTF-16 code units, while this phase counts code points. A published title with many astral characters (for example 120 emoji, 240 code units) is valid here but may need shortening when later edited in the KB form.
