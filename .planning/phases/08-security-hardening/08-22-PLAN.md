- Harness (plan 08-14): `createComposeHarness(suite, { overlays?, profiles?, extraEnv? })` with `project` (`aida`), `runId`, `runDir`, `envFile`, `volumeNames`, `imageNames`, `composeArgs(envFile?)`, `dc`, `preflight`, `startStack`, `requireStack`, `waitForHealthy`, `probe`, `resetRateLimits`, `restartApp`, `appEnv`, `recreateApp(overrides)`, `restoreApp()`, `teardown()`; result lines `CONTAINER-SUITE-RESULT` and `CONTAINER-SUITE-TEARDOWN`; failures start with `NOT RUN:`, `BLOCKED:` or `FAILED:`; the four-state reporter and tests/container/support/four-state-check.mjs (R2-8). `startStack` renders the config with every overlay and profile and refuses any volume or built image that is not run-scoped, any published port and any name collision. `extraEnv` values are written to the run's env file, so they must be single-line (base64 is).
- Limits: `/api/health` 60 per minute per identity and 120 per minute shared, in memory (08-12); intake 5 per hour per identity, checked before the body (08-11); `/api/health/probe` unthrottled and refused by Caddy with `@healthprobe path /api/health/probe*` and `respond @healthprobe 404` (08-20). Requests from a `docker compose run` container to `http://caddy` reach Caddy from that container's IP, which Caddy writes into X-Forwarded-For. The in-memory throttles live in the app process; restarting or recreating the app container empties them.
- `TRUSTED_PROXY_HOPS=3` with Caddy overwriting X-Forwarded-For gives every request a one-entry chain, shorter than 4, so every request fails closed into the shared bucket (plan 08-10). docker-compose.yml passes `TRUSTED_PROXY_HOPS: ${TRUSTED_PROXY_HOPS:-}` to app (plan 08-18).
- The app healthcheck runs every 10 s against `/api/health/probe` (08-20); `docker inspect --format "{{json .State.Health}}"` returns `Status` and up to five `Log` entries with `Start`, `End` and `ExitCode`; Docker writes those timestamps with the VM clock, which is also the clock inside every container.
- Caddy path matcher (Context7, recorded in plan 08-20): case-insensitive; a trailing `*` is a prefix match; the request path is cleaned of dot segments, repeated slashes are merged and the path is decoded before matching. Whether an encoded slash (`%2F`) is decoded for matching is not verified; the corpus decides.
- The `caddy:2` image runs as root with busybox `sh` and `base64`; the run-scoped app image (`aida_ct_<runid>_app`) has `node`. On macOS the temp directory may not be shared into the Colima VM, so generated files reach containers through base64 environment variables, never through a bind mount.
