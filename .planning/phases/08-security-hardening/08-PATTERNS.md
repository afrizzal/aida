### `src/proxy.ts` (middleware) — D-11 to D-14

**Analog:** itself (58 lines). Current structure, lines 32-58:
```typescript
export function proxy(request: NextRequest) {
  const { pathname } = request.nextUrl;

  if (BLOCKED_PUBLIC_ROUTES.some((p) => pathname.startsWith(p))) {
    return NextResponse.json({ error: "..." }, { status: 403 });
  }

  if (PUBLIC_PREFIXES.some((p) => pathname.startsWith(p))) return NextResponse.next();

  const sessionCookie = getSessionCookie(request);
  if (!sessionCookie) {
    if (pathname.startsWith("/api/")) {
      return NextResponse.json({ error: "unauthorized" }, { status: 401 });
    }
    return NextResponse.redirect(new URL("/login", request.url));
  }
  return NextResponse.next();
}

export const config = { matcher: ["/((?!_next/static|_next/image|favicon.ico).*)"] };
```
- There are three `NextResponse.next()` exits (line 45 public, line 55 authed) plus JSON/redirect exits. D-11 says the CSP goes on **every HTML path, public included**, so the nonce/CSP must be applied to both `next()` exits, not only after the session check. Pattern: build the nonce once at the top, build request headers with `x-nonce` and `Content-Security-Policy` **set** (overwriting any client value, D-12), then return `NextResponse.next({ request: { headers: requestHeaders } })` and set the same CSP on `response.headers`. Wrap that in one local helper so the two `next()` exits cannot drift.
- `BLOCKED_PUBLIC_ROUTES` must stay first (comment lines 27-29 explains why). Keep the long why-comment style (lines 14-29) for the CSP block: name D-11/D-14 and the Radix `style-src-attr` reason.
- D-14: `Referrer-Policy` default plus `no-referrer` when `pathname.startsWith("/status")`; `X-Content-Type-Options: nosniff` on all responses.
- Edge-safety: `tests/unit/proxy.test.ts` header says "without importing Prisma (Edge-safe)". The CSP helper must not import `@/lib/db` or anything that does; use Web Crypto (`crypto.randomUUID()` / `crypto.getRandomValues`) for the nonce, which works in both runtimes.
- The matcher excludes `_next/static`, `_next/image`, `favicon.ico`. API routes do pass through; decide whether JSON API responses get the CSP (harmless) or only HTML paths.
