Rules (charter and ROADMAP):
- One test process at a time; long commands write to a log under a `mktemp -d` directory in `${TMPDIR}`; read each exit code without a pipe.
- If `tsc` or the build breaks after repeated E2E runs because of truncated `.next/dev/types`, delete the gitignored `.next/` and rerun.
- Audit: record plain `pnpm audit --prod` as is (non-zero while any advisory remains); the security bar is `--audit-level=high`; a residual high or critical is red with its reason, never passed. Network failures are "blocked".
- Compose gate: if port 80 or 443 is in use, do not stop other services; record and park. Never stop, remove or change containers or volumes outside project `aida`, `aida-dev-db` and the test projects this phase created. `docker compose -p aida down` without `-v`.
- Known external blocker (2026-11-08): image builds can stall at `@prisma/engines` postinstall; record as blocked with evidence, never use a mirror.
- `RUN-LOG.md`, `LAPORAN.md`, `ANTREAN.md` and `REQUIREMENTS.md` belong to the orchestrator; this plan does not edit them. The orchestrator writes the release safe point into LAPORAN.md from this gate file.
- The compose gate reads the operator's existing `.env` (never edits it). If required values are missing, record the check as blocked with the variable names (not values).
