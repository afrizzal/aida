<objective>
Prove AIDA-28's acceptance: an E2E test asserts the CSP header and zero CSP violations on login, inbox, ticket, public request and public status pages, including a popover and a theme switch (D-15), and fix whatever runtime style or script the strict policy blocks without weakening it (D-11, D-12). Wave 4, after the CSP header (08-07) and the `get-nonce` dependency (08-04).

Purpose: a nonce policy that breaks toasts, dropdowns or theme switching is not shippable, and one that is loosened to pass is not secure. Verified in node_modules before planning: sonner 2.0.7 injects a style tag at module load without a nonce (`__insertCSS`), and react-style-singleton (used by Radix scroll lock through react-remove-scroll) stamps a nonce only when `get-nonce`'s `setNonce` was called. The E2E run decides which fix is needed.
Output: the permanent CSP E2E spec, the remediation it proves necessary, and unit guards for it.
</objective>
