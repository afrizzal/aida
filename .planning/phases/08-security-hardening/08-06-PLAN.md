<objective>
Remove the admin-facing connection-test error oracle (D-25, AIDA-31, F-08) by returning one of four fixed categories from all four connection tests, and close two small findings: `addTag` gates before validating (D-28, F-11) and `sla-flag` documents why its raw SQL has no org filter (D-28, F-13). Wave 1 per D-30.

Purpose: raw failure text let an org admin map the internal network through the Ollama base URL or mail host fields. Categories reduce that oracle; they do not remove SSRF or timing channels (docs/SECURITY.md says so in plan 08-15).
Output: a pure classifier module, four rewritten catch paths, three buttons on one message map, an addTag reorder, an sla-flag comment, and unit tests.
Canon note: SSRF itself is canon security (covered by /gsd-secure-phase); this plan only removes the error-text oracle.
</objective>
