<objective>
Add a nonce-based Content-Security-Policy with `strict-dynamic` to every HTML response, set in `src/proxy.ts` on public and authenticated paths alike, plus `nosniff`, `X-Frame-Options` and a referrer policy that keeps the status token out of `Referer` (D-11 to D-14, AIDA-28, F-15). Wave 2 after the `next` upgrade (D-30).

Purpose: without a CSP an injected script runs freely. The nonce policy blocks inline script that lacks the per-response nonce and limits `connect-src` to the same origin.
Output: a pure CSP module, proxy wiring, the root layout passing the nonce to next-themes, and unit tests. Plan 08-08 adds the E2E zero-violation suite and fixes runtime style injections it finds.
Canon note: XSS defence in general is canon (covered by /gsd-secure-phase); this plan implements the specific policy locked in D-11.
</objective>
