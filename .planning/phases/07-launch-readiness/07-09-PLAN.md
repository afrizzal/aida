<!-- The invariants this pass verifies, stated so you check the right things. -->

**Encryption at rest.** `src/lib/crypto/secret-box.ts` is the codebase's ONE AES-256-GCM primitive (`encryptSecret`/`decryptSecret`, `node:crypto` only, fresh 12-byte IV, blob layout `iv|authTag|ciphertext` base64-packed into `Setting.value`). Credential-bearing Setting keys: `email:imapPasswordEnc`, `email:smtpPasswordEnc`, and the `llm:*` / embedding provider API keys. Every one must round-trip through this module and never be stored or logged in plaintext.

**Authorization.** `requireOrgAdmin()` (`src/lib/authz.ts`) is the standard server-side admin gate and must be the FIRST statement of every mutating Settings Server Action. `getScopedDb()` (`src/lib/session.ts`) calls `requireSession()` and binds `scopedDb(orgId)`. `src/proxy.ts` (renamed from middleware.ts in 07-01) gates routes with `PUBLIC_PREFIXES = ["/login","/setup","/api/auth","/api/health","/request","/status","/api/public"]`, returning 401 JSON for unauthenticated `/api/*` and redirecting page routes to `/login`.

**Tenant isolation.** `scopedDb(orgId)` injects `organizationId` via Prisma `$extends`. It does NOT intercept raw SQL — every `$queryRaw`/`$executeRaw` touching tenant tables must filter `organizationId` explicitly in the SQL itself. `src/lib/tickets/search.ts` is the documented precedent.

**AIDA-20 safeguards.** Fenced/escaped prompts + redaction (`src/lib/llm/redact.ts`, `src/lib/rag/prompt-safety.ts`), the append-only `AuditEvent` trigger (`aida_audit_event_no_update_delete`), and "no network egress except to the configured LLM endpoint". Automated proofs that already exist: `tests/integration/triage-injection.test.ts`, `tests/integration/audit-append-only.test.ts`, `tests/unit/llm-redact.test.ts`, `tests/integration/draft-generation.test.ts` (groundedness/injection).

**Public surfaces and their controls:** `/request` + `POST /api/public/intake` (honeypot `company_website`, `checkRateLimit("public-intake")`, per-file `file-type` byte sniff, MIME allowlist, size caps); `/status/[token]` (bearer statusToken, server-side `visibility: "PUBLIC"` filter); `POST /api/public/status/[token]/follow-up` (honeypot + `checkRateLimit("status-follow-up")`); `GET /api/public/status/[token]/attachments/[id]` (authorised through a `{ ticketId, visibility: PUBLIC }` join); `POST /api/public/status/[token]/csat` (honeypot + `checkRateLimit("status-csat")`). Rate-limit hits are stored as `sha256(ip + RATE_LIMIT_PEPPER)` — raw IPs are never persisted.

**New surfaces introduced in Phase 7 that must be inside the audit boundary:**
- `src/app/(app)/settings/branding/actions.ts` (07-03) — a new mutating Server Action.
- `src/lib/demo/bootstrap-demo.ts` + `src/lib/demo/identities.ts` (07-07) — a documented-credentials path gated on `DEMO_MODE === "true"`.
- `prisma/seed.ts` + `src/lib/demo/*` (07-02) — must write no real secret and must not enable AI.
- `scripts/backup.sh` / `scripts/restore.sh` (07-04) — must not hardcode credentials.
- `.github/workflows/*` (07-05) — must not echo secrets; `.env.example` must contain only placeholders.
