**The quick start that actually works** (`docker-compose.yml` + `Caddyfile` + `.env.example`):
```bash
git clone https://github.com/afrizzal/aida.git
cd aida
cp .env.example .env
# set POSTGRES_PASSWORD, and generate three secrets:
#   openssl rand -base64 32   -> BETTER_AUTH_SECRET, RATE_LIMIT_PEPPER, APP_ENCRYPTION_KEY
docker compose up -d
```
Then **`http://localhost`** — Caddy publishes ports 80/443; port 3000 exists only inside the compose network and is the `pnpm dev` URL, not the compose URL. Health check: `curl http://localhost/api/health`.
