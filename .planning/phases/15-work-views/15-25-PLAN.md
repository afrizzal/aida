6. **Validity per step.** A step's result stands for the tested commit only when no file that step covers changed after its run (pathspecs in Task 3 Z). This keeps the Phase 14 rule "a result is valid only for the commit it ran on" without rerunning the whole suite after a test-only fix.

10. **Compose stack not run.** The charter requires `docker compose -p aida up` only at the end of Phases 08, 13 and 17; Phase 15 changes no compose file (grep row). Only two rows are blocked (O-1).
11. **Evidence format.** A test is cited as its path followed by double-quoted titles copied verbatim; a script checks every title against its file, so no row can cite a test that does not exist.
12. **Manual items** are copied, grouped and marked `[open]` with their source plans; the gate closes none of them.
