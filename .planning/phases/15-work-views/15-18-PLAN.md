11. **Versions (revised for the open-editor rule of the 15-15 revision).** TaskView keeps the newest known version (the server's or the last success result). A call made with no editor open for its field (a select changed by typeahead on its closed trigger) sends that version. An editor that is open sends the version recorded when it opened, even if a refresh, a revalidation or a Reload has since brought newer data. Opening means: the title or description editor opened, a date or estimate input focused, the labels popover or a select opened (`beginEdit(field)`); `endEdit(field)` runs when the commit ends or the edit is cancelled. So a change made elsewhere while the editor was open makes the commit CONFLICT instead of overwriting it. When this view's own write succeeds with expectedVersion e and result version r, the editors that opened on e move to r: the server accepted e, so the change from e to r is only this view's write. Editors that opened on an older version stay there. An open editor's draft is local state seeded when it opened, so new server data never replaces typed text. TaskView and its editors are not keyed by version or by the data object, so a refresh re-renders them in place without remounting. A refresh whose load is notAvailable replaces TaskView (drawer frame state notAvailable; on the page, `notFound()`), which unmounts every editor. `runEdit` sends nothing after unmount or once `gone` is set, so a blur during that unmount sends no call.
