# Phase 15 — UI Design Contract

> Visual and interaction contract for AIDA-72 to AIDA-80 and AIDA-106 (project list and detail, task drawer and page, List, Board, Table, Calendar, Timeline, Files, saved views, workspace Tasks, Calendar and Timeline). Generated by gsd-ui-researcher under the run charter, unattended, with no user questions. Every choice that `15-CONTEXT.md` leaves open is marked **[RL]** and listed under "Researcher choices". To be verified by gsd-ui-checker.
>
> **Binding parent:** `.planning/DESIGN-SYSTEM.md`. Conventions carried from `12.2-UI-SPEC.md` and `12.1-UI-SPEC.md` **[P12]**: spacing 4/8/16/24/32; 16px callout padding; `text-[13px]` overrides on shadcn internals; 15px dialog titles; inline `role="alert"` callouts in dialogs; toasts for success only; "Nothing was changed." before every returned refusal; a separate "result is not known" row for UNKNOWN and rejected calls; disabled-with-reason controls (`aria-disabled="true"` plus `aria-describedby` to a 12px muted reason); `LocalDateTime` for timestamps; warning notices with `text-foreground` text and a `text-warning` icon.
>
> **Clean-room (charter, binding).** All copy, layout and visuals below are written from `FITUR-PROJECTS.md` behaviour lines and AIDA's own design system. No text, CSS, icon set, colour, sample data or layout of the reference product is used, and this document does not name it. Every string in the Copywriting Contract is new.
>
> **Scope (closed list):** Surfaces 1 to 18 below. Out of scope [CTX deferred]: Home, My Tasks, notification center, Activity page, search, Members and Teams pages, team assignment UI, favorites and archive pages, preferences, palette commands, global shortcuts, context menus, shared project views, workspace saved views, inline file previews, bulk archive and bulk delete, a sidebar project list, and hand reordering of projects.

Source legend: **[CTX D-nn]** = `15-CONTEXT.md` decision; **[Knn]** = run decision in `15-CONTEXT.md`; **[REQ]** = AIDA-72 to 80, 106; **[DS §n]** = `DESIGN-SYSTEM.md`; **[code]** = code at `ed9c993`; **[P12]** = 12.1/12.2 UI-SPEC convention; **[C7]** = checked through Context7 on 2026-11-10; **[RL]** = researcher choice, conservative.

## Typography

| Role | Size | Weight | Line height | Where |
|------|------|--------|-------------|-------|
| Caption | 12px (`text-[12px]`) | 400 | 1.5 | Chips, keys, dates, counts, field help, disabled reasons, card meta, calendar day numbers, timeline scale |
| Body / label | 13px (`text-[13px]`) | 400 / 600 | 1.5 | Rows, cards, table cells, toolbar controls, menus, notices, callouts, dialog descriptions, labels (600), comments, Markdown preview |
| Title | 15px (`text-[15px]`) | 600 | 1.2 | `DialogTitle`, card headings, group headers, drawer task title, calendar range heading (`tracking-tight`) |
| Page title | 18px (`text-[18px]`) | 600 | 1.2 | `<h1>` of `/projects`, project name, task page title, workspace pages (`tracking-tight`) |

- Explicit `text-[Npx]` only [DS §3, §8 rule 6]. `text-[14px]` appears only inside the existing `EmptyState` body and sidebar nav items [code], never in new text. The existing `EmptyState` body renders 14px (inherited from the component, DESIGN-SYSTEM line ~87), not a new size.
- Overrides as [P12]: `DropdownMenuItem`, `SelectTrigger`, `SelectItem`, `Input`, `Textarea`, `Button size="sm"` and `Button` → `text-[13px]`; `DialogTitle` → `text-[15px] font-semibold tracking-tight`; `DialogDescription` → `text-[13px]`.
- Two weights for new text: 400 and 600. Existing 500 in the sidebar is untouched.
- Task keys and file sizes use `tabular-nums`; keys use `font-mono text-[12px] text-muted-foreground` [RL]. Counts use `tabular-nums`.
- Card and row task titles clamp: Board card `line-clamp-2`; List, Table and Timeline `truncate` with the full title in a Tooltip.
- **Dates [RL, CTX D-13].** Dates are `CalendarDate` strings formatted without the browser zone: `Intl.DateTimeFormat("en-GB", { timeZone: "UTC", ... })` applied to the UTC midnight of the string. Formats: full `10 Nov 2026`; same-year short `10 Nov`; weekday `Mon`; month heading `November 2026`; week heading `9 – 15 Nov 2026` (en dash with spaces). Timestamps (comments, files, history) use the existing `LocalDateTime`. Per-user date format waits for AIDA-98.

## Surface 18 — Shared screen states and the outcome map [CTX D-03, D-21, K88]

- **Loading**: each route has `loading.tsx` with Skeletons shaped like the view (rows `h-10`, cards `h-[96px]`, a 7×5 grid of `h-[112px]` cells, timeline rows `h-9`). Buttons that wait show `Loader2 size-4 animate-spin motion-reduce:animate-none` with their pending label.
- **Not available** (missing, unreadable, deleted project or task; `notFound()`): EmptyState `SearchX` "Not available heading/body" plus outline link "Go to Projects". One component, one copy, used by `/projects/[id]/*` and `/tasks/[id]` [K74].
- **Error boundary** (`error.tsx` per route group, the `tickets/error.tsx` pattern): destructive callout "Load error" with link-style "Try again" (`reset()`).
- **Access lost while open**: any action or load returning NOT_FOUND shows the callout "Access lost" with outline "Reload"; Reload re-renders the route, which then shows the not-available state if access is really gone. MEMBERSHIP_ENDED uses its row and the existing session handling.
- **Outcome callout** (`outcome-callout.tsx`): every returned refusal = destructive callout starting "Nothing was changed." + the code row; CONFLICT adds outline "Reload"; UNKNOWN = warning-style notice (not destructive, because nothing is known to have failed) with the "Outcome unknown" row; the view reloads at once and the control that made the call (and the same control on the same item) stays disabled until the reload completes [K88]. A click after UNKNOWN never repeats the call by itself.
- **Narrow screens**: below `md` the Board, Calendar grid, Table and Timeline scroll inside their own regions; the drawer is full width below `sm`; toolbars wrap. The sidebar stays `w-60` [DS §6].
- **Dark mode**: token-only classes; no `dark:` overrides needed. The contrast E2E is extended to the new pages in both themes [CTX D-21]; the human dark-mode review stays open.

## Researcher choices [RL]

1. **Tabs as links** (`nav` + `aria-current`), not Radix Tabs, because each tab is a URL.
2. **Drawer** is a hand-written `sheet.tsx` over the installed `radix-ui` Dialog; no registry fetch. The Next 16 slot needs `default.tsx` (Context7).
3. **Project settings live in dialogs** opened from the header and the actions menu (Edit, Members, Labels, Milestones), because D-01 lists no settings route. Owner item 15-o1 may move them.
4. **Archive scope** is a "Current / Archived" segmented control; archive and restore need no dialog.
5. **Filters** live in the URL and in saved views, not in view state (D-18 lists none).
6. **Calendar mode** and **Timeline start** live in the URL only; **zoom** and grouping in view state.
7. **Timeline windows**: Day 4 weeks, Week 16 weeks, Month 12 months; day widths 40/16/4 px; **no pointer resize handles** in this phase.
8. **Keyboard "Move to {status}" places at the top** of the target column (anchor null, always valid). "Move down" on the last loaded card with more unloaded is disabled with a reason.
9. **Table keyboard** follows the ARIA grid pattern: one Tab stop; Tab moves cell to cell only while editing.
10. **Bulk selection only in the project List**, no workspace bulk and no workspace quick add (labels and milestones are per project).
11. **Saved view open** applies its payload and pauses view-state writes; "Modified" marks unsaved changes; unsaved changes are lost on reload.
12. **Workspace Tasks form** (list, board, table) is in the URL `?form=`.
13. **No List Move menu, no Table drag**: neither view offers pointer drag, so no keyboard alternative is owed there; subtask order uses Move menu items only.
14. **Calendar "Set date…"** moves the task so the chosen date becomes its due date (or start date when it has no due date), keeping the duration.
15. **UNKNOWN** uses a warning-style notice, not a destructive one, and the view reloads at once.
16. **Overview** shows per-status counts only if `getProjectProgress` already returns them; no new progress query is added for it.
17. **Date display** `en-GB` style through UTC formatting until AIDA-98.
18. **Files has no upload button**; uploads happen in the task view.
