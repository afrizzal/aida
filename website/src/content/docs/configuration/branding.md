By the end of this page your workspace's name will be showing up everywhere a customer or agent
sees the AIDA brand mark.

## The one field

Settings → Branding has exactly one field: **workspace name**. It defaults to your
organization's name if you never set it, and it's applied to:

- The app sidebar brand block agents see
- The public request page (`/request`)
- The public status page (`/status/<token>`)
- The from-name on outbound email

Only workspace admins can change it — the Server Action enforces this server-side, not just by
hiding the field in the UI.

## What's not here yet

Logo upload is **not available in v1**. The workspace name is the only branding surface today.
